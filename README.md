# Bluetti AC180P для Galaxy Watch 7

Автономное приложение для Wear OS: часы сами подключаются к станции по Bluetooth, телефон не нужен.

## Что показывает

- **Главный экран** — кольцо заряда (%), сколько осталось до разряда или до полного заряда, входная и выходная мощность (сеть / солнце, AC / DC), переключатели выходов AC и DC. Данные обновляются каждые 4 секунды, пока экран открыт.
- **Плитка (Tile)** — заряд, оставшееся время и мощность. Достаточно провести по циферблату, приложение открывать не нужно.
- **Усложнение для циферблата** — заряд в виде кольца или текста, плюс оставшееся время (`3ч20`, при зарядке `↑0ч45`).

## Как считается оставшееся время

Ёмкость AC180P — 1440 Вт·ч.

- Мощность батареи = вход × 0.90 − выход / 0.88 (КПД заряда и инвертора, оценочные значения).
- Если батарея разряжается: оставшаяся энергия делится на мощность разряда.
- Если заряжается: недостающая энергия делится на мощность заряда.
- На главном экране мощность сглаживается, чтобы цифра не прыгала.

Это оценка. При нагрузке меньше 3 Вт выводится «нет нагрузки». Константы можно поправить в `protocol/Ac180p.java`.

## Установка на часы

1. **Android Studio** (бесплатно): https://developer.android.com/studio. Откройте папку `BluettiWatch`, дождитесь Gradle Sync. Если Studio предложит обновить Gradle/AGP — можно соглашаться.
2. **Режим разработчика на часах**: Настройки → О часах → Программное обеспечение → 5 раз нажмите «Версия ПО».
3. **Отладка по Wi‑Fi**: Настройки → Параметры разработчика → включите «Отладка ADB» и «Отладка по Wi‑Fi». Часы и компьютер должны быть в одной сети Wi‑Fi.
4. **Сопряжение**: на часах «Отладка по Wi‑Fi» → «Сопряжение нового устройства». В Android Studio: список устройств → *Pair Devices Using Wi‑Fi* → *Pair using pairing code*. Или из терминала:
   ```
   adb pair IP:ПОРТ_СОПРЯЖЕНИЯ КОД
   adb connect IP:ПОРТ
   ```
5. Выберите часы в списке устройств и нажмите ▶ **Run**. Либо соберите `Build → Build APK(s)` и выполните `adb install app/build/outputs/apk/debug/app-debug.apk`.

## Первый запуск

1. Разрешите доступ к Bluetooth («Устройства поблизости»).
2. **Закройте приложение BLUETTI на телефоне** или выключите на нём Bluetooth: станция держит только одно BLE‑подключение.
3. Выберите станцию в списке (имя вида `AC180P2438…`).
4. Плитка: долгое нажатие на текущую плитку → «+» → **Bluetti AC180P**.
5. Усложнение: долгое нажатие на циферблат → «Настроить» → ячейка усложнения → **Заряд Bluetti**. Не все циферблаты Samsung поддерживают сторонние усложнения; подойдут, например, «Info Modular» или Pixel‑подобные.

## Важно знать

- **Фоновое обновление** (по умолчанию включено) раз в ~15 минут подключается к станции на несколько секунд, чтобы обновить плитку и усложнение. Если данные старше 5 минут, открытие плитки тоже запускает обновление. Wear OS может откладывать фоновые задачи для экономии батареи. На время этого подключения приложение BLUETTI на телефоне не сможет подключиться к станции. Выключается на главном экране.
- **Управление выходами AC/DC** — экспериментальная функция. Открытые библиотеки пока не проверяли запись по шифрованному каналу. Чтобы случайно не обесточить нагрузку, выключение требует двойного нажатия.
- Дальность Bluetooth — около 10 м в прямой видимости.
- Если станция не отвечает: выключите и включите Bluetooth на часах, закройте приложение BLUETTI на телефоне, подойдите ближе.

## Как это устроено

AC180P использует протокол Bluetti IoT V2 с шифрованием BLE: рукопожатие ECDH P‑256 с подписями ECDSA, затем AES‑256‑CBC. Данные читаются Modbus‑командами.

| Регистр | Значение |
|---|---|
| 102 | заряд, % |
| 140 | мощность DC‑выхода, Вт |
| 142 | мощность AC‑выхода, Вт |
| 144 | мощность DC‑входа (солнце/авто), Вт |
| 146 | мощность AC‑входа (сеть), Вт |
| 2011 / 2012 | выход AC / DC (1 = вкл) |

Протокол и регистры взяты из открытых проектов [bluetti-bt-lib](https://pypi.org/project/bluetti-bt-lib/) / [hassio-bluetti-bt](https://github.com/Patrick762/hassio-bluetti-bt) (Patrick762) и [nhurman/bluetti_mqtt](https://github.com/nhurman/bluetti_mqtt). Реализация протокола на Java (`app/src/main/java/.../protocol/`) проверена на побайтное совпадение с bluetti-bt-lib на эмуляторе станции: рукопожатие, ключ сессии, шифрование команд, сборка фрагментированных ответов, CRC.

```
app/src/main/java/com/example/bluettiwatch/
├── protocol/   BluettiCrypto, BluettiSession, Modbus, Ac180p  — протокол (чистая Java)
├── ble/        BluettiBleClient                               — GATT‑подключение
├── data/       StationRepository, StationPrefs, Format        — опрос, кэш, оценка времени
├── ui/         Screens                                        — Compose for Wear OS
├── tile/       StationTileService                             — плитка
├── complication/ BatteryComplicationService                   — усложнение
└── work/       RefreshWorker                                  — фоновое обновление
```

Приложение неофициальное и с Bluetti не связано.
